# painel.negocioscreators.com

Publica https://painel.negocioscreators.com juntando os sites dos repositórios de cada cliente (lista em `sites.json`).
Os sites continuam nos repositórios originais; este repo só monta e publica a cada 20 minutos (ou na hora, em Actions > "Publicar no domínio" > Run workflow).

Fonte editável: `Negocios Creators/dominio/` no vault vibehub-os.
